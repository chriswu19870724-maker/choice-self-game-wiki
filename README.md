# 选择成就真我：项目 wiki 与当前共识

> 本页是当前设计共识入口。新结论只记录已明确确认的方向；提案细节、数值与验证结果分开标注。
>
> **当前状态：** 铸剑山庄「铸剑—遣徒—历练—收获—再铸」主线；首个垂直切片范围已收敛。
>
> **最近整理：** 2026-11-13

## 一句话概念

一款以“选择成就真我”为内核的单机武侠／仙侠游戏。玩家通过自己的行动与抉择塑造所成为的人；世界会记住这些行动，但不替玩家指定唯一的道德答案。

## 当前主线方向

玩法主线从旧方案的「铸剑—卖剑」经营链，转为以风险和代价推动的循环：

**手动铸剑 → 选择弟子与历练地 → 在可读风险下做节点抉择 → 收获／损失 → 再铸。**

剑既是玩家亲手打造的成果，也是历练中的投入；弟子是有名字、经历与关系重量的具体人物；历练让玩家在看得懂风险的前提下作选择，并承担相应结果。详细边界见[当前主线玩法方向](docs/mainline-gameplay-direction.md)。

### 实现引擎方向

**已确定：** 使用 Godot 开发本项目。此决定仅确定引擎选择；Godot 具体版本、渲染器、目标平台与导出矩阵均未决定，不据此推断其他实现架构。

## 首个垂直切片

首个切片只验证核心循环，范围收在：**一把剑、一名具名弟子、一个历练地、3–5 个历练节点，以及一次失败后的重铸。** 切片须保留手动铸剑、可读风险和节点抉择；不以完整经营系统或长线内容量作为前置条件。

原提案中的概率、配平公式、弟子属性、剑品等细节仍须验证，不能仅因出现在提案里就视为已定案。

## 里程碑概览

| 阶段 | 周期（相对提案） | 当前工作定义 |
| --- | --- | --- |
| 垂直切片 | 0–2 月 | 完成上述最小循环，并呈现一次失败后重铸。 |
| 验证 | 3–6 月 | 验证锻造手感、风险可读性、损失是否可理解及玩家是否愿意再铸；据证据调整方向。 |
| 扩展 | 6–12 月 | 仅在验证结果支持后扩展内容与系统；具体范围另行决策。 |

周期是方案中的相对阶段，不代表已确定日历排期或上线承诺。成功率、风险偏好、死亡接受度等数值均为**待验证假设**，不是验收门槛或承诺。四流派、永久死亡和 20 小时内容不直接锁入 MVP。详见[里程碑与验证假设](docs/milestones-2026-11-13.md)。

## 当前待决策与待验证

- 手动铸剑的具体操作、时长、反馈，以及它如何影响剑的历练表现。
- 历练地信息如何呈现；3–5 个节点的类型、选项与风险提示怎么设计。
- 失败的具体后果、损失边界、重铸成本与可回收内容。
- 具名弟子的个性与成长在首切片中需要表现到什么程度。
- 如何验证成功率、风险选择、失败后再铸意愿等假设；目前没有已确认的数值目标。
- 验证后是否加入四流派、永久死亡或长时长内容，均待后续证据与决策。

## 核心设计原则

- 选择要有可感知的后果，但不以善恶标签替玩家判断。
- 风险须可读，重要损失不能来自玩家事前无法理解的黑箱。
- 先验证一个完整、可玩的核心循环，再决定是否扩充系统与内容。
- 将提案、待验证假设、当前共识和已观察到的测试事实分开记录。
