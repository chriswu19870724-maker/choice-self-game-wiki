## 一句话概念

一款以“选择成就真我”为内核的单机武侠／仙侠游戏。玩家通过自己的行动与抉择塑造所成为的人；世界会记住这些行动，但不替玩家指定唯一的道德答案。

## 当前主线方向

玩法主线从旧方案的「铸剑—卖剑」经营链，转为以风险和代价推动的循环：

**手动铸剑 → 选择弟子与历练地 → 在可读风险下做节点抉择 → 收获／损失 → 再铸。**

剑既是玩家亲手打造的成果，也是历练中的投入；弟子是有名字、经历与关系重量的具体人物；历练让玩家在看得懂风险的前提下作选择，并承担相应结果。详细边界见[当前主线玩法方向](docs/mainline-gameplay-direction.md)。

### 实现引擎方向

**已确定：** 使用 Godot 开发本项目。首个内部可分享浏览器 Demo 已批准使用 **Godot 4.7.2-stable 标准版／GDScript、Compatibility 渲染器及 Godot Web 导出**；浏览器需要支持 WebAssembly 与 WebGL 2.0，且需尽早做移动浏览器 smoke test。**Playwright 是必需的浏览器 E2E 测试工具，仅用于开发／测试，不随游戏打包。**运行时第三方依赖仍禁止。本决定不构成最终发行平台或浏览器兼容矩阵承诺。

### 首个 Demo 呈现方式

**已确认：** 首个 Godot Demo 使用 **2D UI + 文字节点** 呈现。此决定只限定首个 Demo，不代表后续产品整体采用 2D 或 3D；整体形态仍未决定。

## 首个垂直切片

首个切片只验证核心循环，范围收在：**一把剑、具名弟子阿禾、折锋谷四个历练节点，以及一条经明确警示的失败后重铸验收路线。** 任一节点确认高风险即进入失败路线；只有四个节点全程确认较安全才能避开这次失败及其损失。不强迫每位玩家选择高风险。切片保留手动铸剑、可读风险与节点抉择，不以完整经营系统或长线内容量为前置。

每个节点的路线确认前，都必须明确披露累计映射：任一节点确认高风险即标记为失败路线；只有四节点全程选择较安全路线才能避开这次失败。结果由单一的本次历练状态根据已确认选择确定，不使用隐藏随机；失败结算前不可把损失写成已发生。

原提案中的概率、配平公式、弟子属性、剑品等细节仍须验证，不能仅因出现在提案里就视为已定案。

## 核心设计原则

- 选择要有可感知的后果，但不以善恶标签替玩家判断。
- 风险须可读，重要损失不能来自玩家事前无法理解的黑箱。
- 先验证一个完整、可玩的核心循环，再决定是否扩充系统与内容。
- 将提案、待验证假设、当前共识和已观察到的测试事实分开记录。
