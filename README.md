## 一句话概念

一款以“选择成就真我”为内核的开放探索型叙事游戏。玩家通过行动和抉择，逐渐发现并捍卫自己想成为的人；世界会记住这些行动，但不替玩家指定唯一的政治或道德正确答案。

## 当前共识

### 核心体验

- 让玩家通过自己的选择形成身份，而不是先被一个固定职业、阵营或道德标签定义。
- 选择应带来可感知的后果，影响人物处境、世界状态、信任与未来机会；不简单标注“善／恶”或公布唯一正确路线。
- 让世界对玩家的行动有所记忆，同时容纳多种活法。天道、自然边界、因果与实际代价可以促使玩家思考，但不成为说教式判官。
- 支持不同动机与节奏：强杀、轻松探索、追逐欲望或财富、行侠仗义等路线都可能成立，并面对各自的后果。

### 题材与体验形态

- 当前优先考虑武侠／仙侠作为题材外壳；“选择成就真我”的内核应能迁移到其他题材。
- 以单机叙事体验为主，弱社交作为辅助；不以强 MMO、强制公会或开放世界阵营大战为方向。
- 不同题材可拥有不同的玩法模块，但应服务于同一核心：玩家能通过选择、行动和承担后果，活成自己选择的人。

### 武侠／仙侠玩法素材池

可探索的系统包括功法、斗技、灵宝、丹药、灵宠，以及赌场、炼丹、挖矿、采集、铸造等。它们是可选模块，不代表首版都要实现。

### 角色与社交设想

每位玩家可以创建一个持续成长的 Agent 角色，并赋予出生偏好与初始记忆；角色不应只是编号或固定脚本，而会因经历发展。玩家可能遇到其他玩家的 Agent，在线或离线互动、建立关系，并在共同经历后发展出伙伴关系或出战协作。

关系不应退化为好友列表、单一好感度数值，或“刷满亲密度就服从”的开关。是否信任、合作或并肩作战，应能体现双方经历、处境与选择。以上属于长期方向，尚未进入首个切片范围。

另整理了[炼丹原型灵感研究](docs/alchemy-prototype-inspirations.md)，比较《Potion Craft》《炼金工房》《天国：拯救》《上古卷轴5：天际》等游戏机制，以及《斗破苍穹》《凡人修仙传》的炼药叙事。本轮认可的总体方向是参考药剂工艺：**先让基础合成可完成，再围绕基础结果持续优化**。这不代表具体操作、优化项目、解锁节奏或数值已定案；研究中的其他做法仍属候选灵感，尤其小说提供的是人物目标与资源压力，不是现成的游戏操作系统。

## 首个可玩切片：药铺炼丹

### 场景设想

神医离世后，普通炼丹弟子成为其唯一传人，经营一间药铺。玩家学习基础丹方，为前来求药的人炼丹；来客带来收入，也可能带来稀有药材、奇遇与线索。

炼丹可作为逐步解锁的技能：先让基础合成能够完成，再持续优化炼制结果；入门阶段可考虑丹胚、凝丹等简化前置过程，让玩家用短操作影响成丹结果，之后再逐步开放更复杂的炼丹体系。具体交互、优化方向与解锁节奏仍待验证，不让长期扩展妨碍首版聚焦于最小体验验证。

首个 Demo 的空间范围进一步聚焦为一间药铺：暂不依赖多地图跑图或宏大场景，优先在店内完成来客互动、问诊与线索观察、药材取舍和炼制操作。可参考用户分享的《深空当铺：可能是偷的》店内画面，将来客、柜台、库存与工作台集中到同一空间；参考的是空间组织，不是照搬规则。当前灰盒原型方案收敛为三个可往返交互区，交药前不锁选择，见[药铺单场景探索与交互草案](docs/pharmacy-single-scene-exploration.md)和[三交互区灰盒排期](docs/pharmacy-prototype-plan-2026-11-10.md)。

### 最小 Demo 范围

- 一间药铺作为主要、尽量唯一的实体场景；店内通过人物、物件与状态变化承载互动，首版不以多地图跑动为前提。
- 一位主要的求药者。
- 一张基础丹方。
- 少量药材，其中有一味稀缺药材。
- 一种玩家可理解、可操作的短炼丹过程；先完成基础合成，再验证持续优化的空间。可从丹胚、凝丹等简化环节入手；具体优化项未定。
- 一个会改变后续情境的关键选择。

### 候选草案：魏槐求药

已将魏槐求药流程和极简试玩记录表整理为[首轮原型方案](docs/wei-huai-quest-script-draft.md)，状态为**首轮原型方案／待试玩验证**，不是最终设定。流程收紧为：线索观察／问诊 → 判断 → 两种都有效的治疗方案（急治消耗稀缺药；缓治使用常见药、但需多休息一晚）→ 一次短控火 → 可见后果。病因（包括矿尘等可能性）、具体药材与控火手法仍未定案；漏看线索或控火失手不能阻断基础救治。

稀缺药留给修习／考核或卖药周转的机会成本只在库存／账本中显示，不扩成第三、第四条剧情线；这份机会成本须在选方前可见，选后有一处清晰状态反馈，交药前仍可改选。首轮试玩约 5 人只是工作目标，测试后再调整。首席游戏策划于 2026-11-10 10:00、原画于 14:00（香港时间）交付，制作人预计 16:00 验收，详见[三交互区灰盒排期](docs/pharmacy-prototype-plan-2026-11-10.md)。

美术灰盒 V0 已交，随后补出 V1。制作人确认 V1 的选前成本和选后差异已画清楚，可作为灰盒基线；急治显示魏槐即时改善、稀缺药减少，缓治显示药材保留、需多休息一晚。停止视觉迭代，不做精绘；待 11 月 10 日 10:00 首席策划交互图对齐热点后，再决定是否小改并接入可点击原型。

## 核心权衡

首轮不把稀缺药的所有用途都做成剧情分支，而是聚焦两种都有效的治疗方案：急治使用稀缺药，缓治使用常见药并多休息一晚。用药库存、账本和休息时间呈现具体代价；修习／考核与卖药周转仅作为稀缺药被放弃用途的账面提示。

### 首版需要验证

1. 玩家实际看到了哪些线索，漏看后是否仍能继续基础救治？
2. 玩家选方前是否看见稀缺药机会成本，选后是否读懂状态反馈？
3. 三个交互区可往返、交药前不锁方案的流程是否清楚？
4. 一次短控火操作是否让玩家感觉可控、有参与感；失手后是否仍能完成基础救治？
5. 两种治疗方案都有效的前提下，差异与可见后果是否清楚？

### 首版明确暂缓

多人互动、AI 伙伴、完整拍卖行、大量丹方与药材、庞大开放世界、强 MMO 结构等，先留作未来扩展方向。只有当切片验证了核心体验后，再决定是否投入。

## 设计边界与原则

- **先验证核心，再扩展内容：** 首版只实现回答关键体验问题所需的最小范围。
- **选择必须有后果，但不必有标准答案：** 让玩家看到代价和影响，不用善恶分数取代理解。
- **世界记得行动：** 后续机会与关系应能回应玩家此前的行为。
- **系统服务于角色表达：** 经济、炼丹、战斗、社交等模块不能只为堆量，应支持玩家选择如何生活。
- **社交自愿且有情境：** 先不把公会、组队或持续在线作为主要进程门槛。
- **可迁移的内核，题材化的模块：** 保留核心体验，允许不同题材采用不同玩法系统。

## 待验证问题

- 入门炼丹的短操作如何表现丹胚、凝丹等过程？玩家操作如何影响结果，之后如何逐步解锁更复杂体系？
- 库存／账本如何清楚呈现稀缺药的被放弃用途，而不把它们扩成首轮剧情分支？
- 如何让玩家在选方前看到机会成本、选后读懂状态反馈，同时在交药前仍可改选？
- 稀缺药材从何而来，玩家何时获知其价值与限制？
- 求药者的需求、困境与信息应如何呈现，才能避免选择像纯粹的“资源计算题”？
- 如何让一间药铺在不依赖地图跑动的情况下保持可探索感；哪些店内物件与阶段变化能支撑问诊、调查、操作和后果反馈？
- 魏槐首轮原型中的线索、两种治疗方案、短控火和可见代价是否易懂；哪些内容需在试玩后调整？
- 选择后果如何延续到下一次游玩或后续章节，同时让因果可理解？
- Agent 的出生偏好、初始记忆与成长如何表达，才能形成角色个性，而不是随机标签？
- 在线／离线互动与好友、伙伴关系如何保护玩家自主性，不演变为刷数值或强制社交？
- 如何在不判定唯一政治或道德答案的前提下，让世界边界、自然规律与行动代价保持可信？
