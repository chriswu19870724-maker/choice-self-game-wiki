- 不把四流派、永久死亡、20 小时内容、具体成功率或损失比例写成已定案。

## 补充确认：体验句与首个 Web Demo 技术基线（2026-11-15）

Chris 确认采用 GDD 中原提议的“每 10 秒体验承诺”：**每 10 秒，玩家不是在等数值跑完，而是在亲手敲下一锤、读懂眼前的风险，或替弟子选一条要承担代价的路，并马上看到剑或历练状态的变化。**

Chris 同时批准以下技术基线，范围仅限**首个内部可分享浏览器 Demo**：

- Godot **4.7.2-stable 标准版**，使用 **GDScript**；
- **Compatibility** 渲染器与 **Godot Web** 导出；浏览器运行需支持 WebAssembly 和 **WebGL 2.0**；
- **Playwright** 为必需的浏览器 E2E 测试工具，只用于开发／测试，不进入游戏包或运行时；
- 在 UI／输入方案锁定前尽早进行移动浏览器 smoke test。

这不是最终发行平台或完整浏览器／设备支持矩阵承诺。Godot 官方 [Web 导出文档](https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_web.html)说明 Web 导出需要 WebAssembly 与 WebGL 2.0，Godot 4 Web 使用 Compatibility；该文档也提示移动 Web 性能限制及 Safari 的 WebGL 2.0 问题。

## 再补充确认：第一关与验收边界（2026-11-15）

Chris 按推荐稿批准 GATE-02 与 GATE-04，具体结论如下：

- 第一关固定为 **折锋谷**，具名弟子为 **阿禾**，共 **四个历练节点**。
- 进入高风险分支前，必须清楚告知风险与可避免代价；较安全选择可以避开这次失败，不强迫每位玩家或每次试玩失败。
- 验收至少有一条有效路线：玩家走入已警示的高风险分支，按其选择与事先披露的规则导致一次失败；不能用隐藏随机数或未披露判定制造关键损失。
- 该失败固定为剑折断、阿禾轻伤后返回；不含永久死亡或永久失去阿禾。
- 失败后重铸复用同一铸剑操作；本切片不扣除货币或材料，不引入相应成本系统。
- Chris 批准 GDD／ACCEPTANCE 的范围与完成条件，包括失败后重铸的验收路线和可避开失败的较安全路线。

GATE-02 与 GATE-04 已勾选；连同 GATE-01、GATE-03、GATE-05，**阶段 0 决策门禁现已全部通过**。GDD、TECH、ACCEPTANCE、README、主线方向与里程碑文档已同步并复核通过；阶段 1 尚未开始、不开始生产代码。

最终发行平台／浏览器矩阵、2D 形态、场景与目录组织、具体输入映射，以及节点台词和呈现细节仍未定；它们不改变已批准的内部 Godot Web 基线与第一关边界，也不改变已完成的文档复核状态。若后续确认其中某项影响实现，再在相关实现前请 Chris 决定。
