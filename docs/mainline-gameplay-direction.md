# 当前主线玩法方向：铸剑—遣徒—历练—再铸

> **状态：当前主线方向，2026-11-15 更新阶段 0 门禁。** 第一关及失败／损失边界已获批准；第二份方案中未被明确采纳的系统、规则和数值仍是提案，不自动成为承诺。

## 为什么切换主线

此前完整架构方案以铸剑、交易和资产成长构成经营循环。当前决定改以《铸剑山庄弟子历练玩法改造方案》为主线，让剑、弟子和历练风险彼此牵连；旧架构留作参考，药铺原型转为旧验证分支。

当前循环不是单向生产与出售，而是：

**手动铸剑 → 选择弟子与历练地 → 在可读风险下做节点抉择 → 收获／损失 → 再铸。**

## 循环中的玩家体验

1. **手动铸剑。** 玩家亲手完成一把剑；锻造操作与剑的表现如何关联仍待原型验证。
2. **选择弟子与历练地。** 首切片固定派出具名弟子阿禾，前往折锋谷；不需要大规模弟子池或多张地图。
3. **阅读风险并做节点选择。** 折锋谷由四个节点构成。高风险分支前必须清楚提示风险及可避免代价；关键结果由玩家选择和已披露规则解释，不藏在黑箱概率中。
4. **承担结果。** 验收路线中，玩家选择高风险路线后，按事先披露的规则导致剑折断、阿禾轻伤返庄；较安全选择可以避开这次失败。失败不是每次试玩的强制结局，不含永久死亡。
5. **再铸。** 失败后以首次锻造的同一操作重铸；首切片不扣货币或材料，也不引入这类成本系统。

## 首个垂直切片的边界

**已确认范围：**

- 一把剑；
- 具名弟子阿禾；
- 历练地折锋谷；
- 四个历练节点，并在可读风险下作选择；
- 一条事前明示风险、由选择和已披露规则导致失败并可重铸的验收路线，同时提供可避免失败的较安全路线；
- 完整表达“手动铸剑 → 派遣与节点抉择 → 收获／损失 → 再铸”的核心循环。

首切片先回答玩法是否成立，不以完整山庄经营、拍卖、榜单、四条成长路线或长线剧情为前置条件。若实现时发现某项内容不是验证该循环所必需，应优先保持切片边界。

## 提案细节与当前边界

第二份方案包含大量可供讨论的细节，例如剑品等级、弟子五维、成功率表、期望值、剑冢与传承、路线定位、建筑和长时长成长节奏。这些内容仍需逐项判断，不因被写入方案就自动成为当前已定规格。

尤其以下内容**不直接锁入 MVP**：

- 四条流派／四流派完整内容；
- 永久死亡或不可回滚的死亡规则；
- 20 小时内容目标；
- 具体成功率、死亡率、风险档位或概率公式；
- 大规模弟子池、完整经济与山庄经营系统。

风险必须可读是当前方向要求；风险概率、收益倍数及玩家接受度阈值则仍属待验证假设。MVP 是否出现死亡、何种损失可承受，需基于原型证据另行决策。

## 待决策事项

1. 锻造的具体操作与时长，以及锻造技术如何影响剑在历练中的表现。
2. 折锋谷的环境信息和可读风险呈现。
3. 四个节点的具体分支、每个选项的文案与信息披露表现。
4. 首切片的失败边界已确定为剑折断、阿禾轻伤返庄；重铸复用同一铸剑操作，不扣货币或材料。具体文案与呈现可在阶段 1 细化，但不得改变该边界。
5. 具名弟子在切片中如何表现个性与关系重量，哪些成长数值可省略。
6. 以何种观察或玩家测试判断循环成立；数值目标与验收门槛尚未确认。
7. 通过验证后，是否扩到流派、永久死亡、剑冢传承或更长时长内容。
