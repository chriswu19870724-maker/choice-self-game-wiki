# 炼丹体验原型灵感：从一招到多层选择

> **状态：总体方向已认可，具体方案待原型验证。** 本文把可核实的作品机制／叙事事实与面向本项目的设计推论分开；具体操作和数值不是系统承诺，也不修改魏槐脚本中的既定处置路线。

## 先说结论

炼丹过程吸引人，不必靠堆很多步骤。更关键的是：玩家看得懂正在改变什么；先能完成基础合成，再持续优化；每次解锁只多一个有意义的选择；结果能回到病患处境、药铺资源或后续线索。熟练后可以更稳、更省材料或追求不同效果，而不只是把成功率变成 100%。

**本轮已认可的总体方向：参考药剂工艺，先完成基础合成，再持续优化。** 已确认的是推进原则；优化项目、交互步骤、技能解锁条件及数值仍待讨论与原型验证。

对魏槐切片，可先试“问诊线索 → 选定原有治疗路线 → 一次短炼丹操作 → 看见药效与人物反馈”。初版只把**丹胚**做成一段短操作，其他炼制自动收束；首次掌握后，再候选解锁一段短的**凝丹**操作。这样先有手感，再逐步叠加，不必开局就做完整炼丹模拟器。

## 魏槐切片：候选的浅入深结构

以下可直接接到现有脚本的“用凝露草炼温脉丹”分支，但**不取代**已经写好的药材取舍、问诊、转诊和低技能保护路线。

1. **初次：只操作丹胚。** 玩家先听完魏槐的线索，选择原脚本已有的治疗路线；随后短按住丹火，在颜色／纹路抵达提示区时松开，完成丹胚。其余过程自动收束。即使时机普通，也得到药效偏弱但可观察、可继续救治的成品；操作做得好，只提高效果上限，不让未学技能成为任务门槛。
2. **第一次掌握后：再解锁凝丹。** 加入一个很短的收束选择，例如把丹胚拖向“稳”或“强”两个区域。稳妥方向让成品更稳定；追求强效则更看重当下缓解，但病因不明时仍要复查，不能把丹药写成根治。具体成效与药性需按项目设定再定。
3. **之后每次只加一层。** 候选解锁顺序可以是：更清楚地辨识凝露草药性 → 一次凝丹补救／更宽的火候窗口 → 常见材料替代或已验证丹方快捷复现。每层都增加新选择，不同时叠加研磨、搅拌、计时、品质、纯度和复杂配伍。
4. **把结果还给人物处境。** 即时显示丹纹、颜色或一声炉响，再由魏槐反馈“胸口缓了多少、手麻是否减轻、是否愿意停用提神散／留下矿砂”。操作结果影响原脚本里的病情、信任和后续线索，不弹出善恶评分；也不让一次失手无提示地伤害病人或卡住任务。
5. **技能扩展表达，不封锁基本路线。** “识药”可让线索更清楚，“稳火”可扩大容错窗或提供一次回退；后续再考虑节材、复现或更多凝丹取向。低技能仍有简式方签、基础处置或转诊路线。

## 可用来验证的小问题

- 不看长教程，玩家能否从颜色／纹路反馈看懂火候变了什么？
- 玩家能否把“问诊得到的线索”联系到炼丹选择，而不把它当成两段互不相干的小游戏？
- 丹胚只有一段短操作时，玩家是否感觉自己参与了炼丹；后来新增凝丹时，是否觉得多了一种选择，而非多了一段负担？
- 成丹结果是否让玩家记住“我为什么这样做、魏槐因此如何”，而不是只记住一个品质数字？

## 参考来源与可靠性提醒

游戏机制优先引用发行商／官方手册、官方商店页，并以可信媒体交叉确认；Skyrim 的基础机制主要参考长期维护的 UESP。小说事实优先参考正版作品页、出版方目录或卷册介绍；《凡人修仙传》的设定资料是整理型页面，具体材料与情节应以正版正文复核。本文的玩法建议均是基于这些事实的设计推论，不是作品原机制的转述。
