# 魏槐求药：V2.5 原型方案（待玩家验证）

> **状态：V2.5 基线已由制作人冻结；本轮部分走查，尚未通过完整手机验收，也未完成正式玩家测试。** 本稿是单场景原型脚本，不是最终设定。正式首次玩家测试招募按用户决定暂缓；旧的约 5 人工作目标已暂停。魏槐的病因（包括矿尘等可能性）、具体药材功效与待测数值不视为定案。

## 目标与范围

在一间药铺内，让玩家观察和问诊、形成判断、从两种都有效的方案中选择、完成控火并看见后果。继续使用求药者／线索、药柜／账本、炼制台三个交互区。实现以制作人冻结的最新版状态文档为准；本轮不扩剧情分支、不制作正式美术。

## V2.5 流程

1. **求药、观察与问诊（H1–H3）。** 魏槐因胸闷、手麻来求药。H1–H3 与问诊均可跳过；玩家可在选方案前回访线索。求药者／线索阶段不出现炉温或控火尺。查看身体部位后有简短反馈，表现为魏槐回应还是主角心里独白，按冻结状态文档实施；不得借反馈把未确认病因写成事实。
2. **形成判断。** 玩家可说明判断或不确定之处；原型不要求猜中病因。
3. **查看代价并选择方案（S2）。** 药柜／账本可跳过，但选方前要能看见稀缺药留作修习／考核或出售周转的机会成本；关键药材库存以警示或高亮突出。急治使用稀缺药，魏槐无需多休息一晚；缓治使用常见药，同样有效，但多休息一晚。两类机会成本只作账面信息，不生成额外剧情线。
4. **未选方案时的炼制台反馈。** 玩家若尚未选方案就进入炼制台，只看到“先选方案”，不开放控火。
5. **控火（S3）。** 滑块往返移动并逐渐加速，火焰随读数变化，过程配有短旁白。只在玩家点击“收火”时判定滑块位置，不自动收火。命中目标温区优化药效／节材；失手仍产出基础药并完成救治。
6. **返程与改方。** 冻结状态图中的两个返程口原样保留：选方后可返回 S2 改方；控火中可取消并返回 S2 改方。不额外增加路线。
7. **交药与结算。** 最终交药前的所有阶段均不扣库存；只在最终交药时结算库存。前置阶段的状态反馈不可表现为库存已实际减少。

## V2.6 问询阶段增补（制作人已定范围）

本节只增加问询内容与「继续问／去选方案」的轻量交互，不改变 V2.5 已冻结的选方、炼制、控火或库存结算规则。制作人确认的两组问答如下，台词按原文呈现：

| 可选追问 | 魏槐回答 |
| --- | --- |
|「你是从什么时候注意到手抖的？」|「大概午后，忙到一半拿水碗时晃了一下。更早有没有，我说不准。」|
|「离开矿井、歇下来后，感觉有变化吗？」|「回到地面坐了会儿，肩膀松了些，手还偶尔抖。今晚还没睡，不知道一觉后会怎样。」|

### 问询交互规则

- 问询可以跳过；玩家问 0、1 或 2 个不同问题后，都能直接去选方案。
- 每答完一问，显示「继续问」与「去选方案」两个去向。「继续问」返回问询选择；未问过的问题优先高亮。已问过的问题仍可重复选择，并播放完全相同的回答。
- 只记录两项是否问过（例如 `asked_onset`、`asked_rest`）；重复提问不新增记录项，也不增加线索计数。
- 追问与回答不改变线索数、库存、诊断、治疗方案或控火状态。回答后不追加主角推论、诊断提示或新线索标记；不暗示病因，也不增加剧情支线。
- 本增补是制作人已确认的 V2.6 范围；目前没有新增实现或测试结果的记录。
