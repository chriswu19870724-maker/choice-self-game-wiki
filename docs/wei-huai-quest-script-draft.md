# 魏槐求药：首轮原型方案（待试玩验证）

> **状态：首轮原型方案／待试玩验证，非定案。** 本稿只用于制作和测试一个单场景纸面或可点击原型，不是最终设定。首轮工作目标是约 5 人试玩；这只是工作目标，测试后再调整。魏槐的病因（包括矿尘等可能性）、具体药材与炼丹／控火手法均尚未定案。

## 首轮目标与范围

在一间药铺内，让玩家观察和问诊、形成判断、在两种都有效的治疗方案中选择、完成一次短控火操作，并看见选择带来的具体代价。三个交互区可往返；交药前可改选。漏线索或控火失手都不能阻断基础救治。暂不制作大地图，也不把稀缺药的其他用途扩成剧情支线。

## 流程

1. **求药与观察／问诊。** 魏槐因胸闷、手麻来求药。玩家可留意症状何时加重、提神散用量变化，以及衣物或药包上的异样痕迹。它们是待观察的线索，不代表任何病因已经确诊。首轮记录玩家实际看了哪些线索。
2. **形成判断。** 玩家根据线索说明自己的判断或不确定之处。原型不要求猜中病因，也不把某种病因写成定案。
3. **先看资源代价，再选择治疗方案。** 两种方案都能有效治疗，差别在代价；稀缺药留给修习／考核或出售周转的机会成本必须在选方前从药柜／账本中可见：
   - **急治：** 使用一份稀缺药，魏槐无需多休息一晚。库存／账本显示这份药原可留给修习或考核，也可出售用于药铺周转；这些只是被放弃用途的账面信息，不生成额外剧情线。
   - **缓治：** 使用常见药，同样有效，但魏槐需要多休息一晚。首轮不再增加其他治疗路线。
4. **保留改选窗口并回显状态。** 选定方案后，用一处清晰反馈显示当前方案及状态；在药交到魏槐手上之前，玩家仍可往返查看三个交互区并改选。
5. **一次短控火。** 在炼制过程中只安排一次短控火操作。具体操作形式、病因与操作之间的设定关系，以及操作对结果的精细影响仍待验证；控火失手仍须完成基础救治，不要据此补写成最终炼丹系统。
6. **交药并呈现后果。** 交药时才锁定方案。清楚呈现治疗有效及所选方案的代价：稀缺药库存及账面机会成本，或多休息一晚。首轮只验证这条短流程是否易懂、有取舍且可操作。

## 本轮边界与待验证事项

- 药铺是首轮唯一场景；不做大地图。
- 稀缺药的修习／考核、卖药周转机会成本须在选方前通过药柜／账本可见，不作为第三、第四条剧情线。
- 三个交互区可往返，交药前不锁选择；选后有一处清晰状态反馈。
- 即使漏看线索或控火失手，也能完成基础救治；急治与缓治两方案均有效。
- 5 人是首轮试玩的工作目标，不是固定验收门槛；依据测试调整。
- 病因（例如矿尘）、具体药材和炼丹／控火手法仍是原型假设，未定案。
- 试玩后重点回看：玩家看到了哪些线索、是否主动看账本、控火是否有掌控感、选择与代价是否能被准确复述。
