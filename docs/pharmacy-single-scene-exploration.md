# 药铺单场景探索与交互草案

> **状态：原型方案，非定案。** 本文记录首个 Demo 聚焦药铺内体验的方向，并整理当前低成本灰盒验证约束。除“先用小场景深挖核心玩法、暂不投入多地图奔跑与宏大场景”外，布局、视角、交互与具体内容仍待原型验证。

## 方向

首个 Demo 不必靠玩家走过许多地图来制造探索感。可以把药铺作为主要、尽量唯一的实体场景，让玩家在一间小店里接待来客、观察线索、查验药材、做问诊与炼制，并亲自决定稀缺物资的去向。场景体量小，仍可以通过信息揭露顺序、操作选择和状态变化承载较深的玩法。

用户分享的《深空当铺：可能是偷的》店铺截图可作空间组织灵感：让来客、柜台、库存物品与工作台集中出现在同一个可读空间里。借鉴的是“一间店铺容纳人物、物品与操作”的布局思路，不是照搬作品规则、美术或界面。

外部世界先作为店内决策的背景：矿区发生什么，可由来客的话、衣物上的矿粉、带来的样本或之后的回访呈现；药材采购可先用委托、送货或事件表现。只有当小场景已验证核心体验，再决定要不要增加出店或地图内容。

## 一次来客如何在一间店里展开

以魏槐来求药为例，可以把原本的多个“场景段落”理解为同一药铺里的几个体验阶段，而不是多个地图：

1. **来客抵店：** 用来客状态提示让求药者进入求药者／线索区；门口、脚步或敲门只是入场表现，不另设第四个热点。
2. **自由观察与问诊：** 玩家可在三个区域间往返，决定先听他说、检查提神散包装，还是留意衣物上的异样。线索与病因关系仍待验证，调查顺序不能让基本救治被技能或单一线索锁死。
3. **归纳与沟通：** 玩家可以说明自己的判断或不确定性；本轮不新增转诊等治疗路线，不需要走到地图另一端才能继续。
4. **柜台上的资源决定：** 药柜／账本呈现库存，并在选方前显示稀缺药原可留作修习／考核或出售周转的机会成本；机会成本只作账面信息。首轮实际治疗只提供两种都有效的方案：急治用稀缺药，缓治用常见药并多休息一晚。
5. **工作台上的短操作：** 炼制台只安排一次短控火操作。具体操作与药材效果仍待验证；控火失手仍须保留基础救治，不把失败做成软锁。
6. **反馈与余波：** 选定方案后给出一处清晰状态反馈，但交药前仍可改选；交药时才锁定方案。回访或后续痕迹属于后续验证，不作为本轮灰盒额外范围。

上述阶段是一种候选流程；不要求每次都完整走一遍，也不预设必须采用点击式或第一人称视角。

## 本轮灰盒的三个交互区

本轮先把单场景收敛为三个可往返区域；早先列出的门口、问诊位、药签等候选细分不另扩成热点，必要的细操作收纳进这三处。目标为柜台视角、16:9 低成本灰盒／线框，不做正式精绘。

| 交互区 | 画面内容与用途 | 必须表达的内容 |
| --- | --- | --- |
| 求药者／线索区 | 求药者、症状与可观察线索；对话、观察、问诊 | 线索是待验证信息；即使漏看也不能卡住基础救治 |
| 药柜／账本区 | 药柜库存与账本信息 | 选方前清楚显示稀缺药留作修习／考核或出售周转的机会成本；只作库存／账面信息，不扩成支线 |
| 炼制台区 | 药材摆放与短炼制操作 | 控火过程可以失手，但仍能完成基础救治；具体控火机制待验证 |

三个区域可以往返访问，不强制唯一点击顺序；玩家在交药前可以改选，不提前锁定方案。选定方案后须有一处明确的状态反馈，让玩家读出当前选择及其影响；最终交药时再提交选择。灰盒里优先使用醒目的文字、简单形状和物件状态变化表达，不依赖精绘。

三个区域可共用一张背景，通过角色姿态、物品状态、可交互提示和简洁镜头反馈表达阶段变化；无需先制作多张大型地图。镜头、热点呈现方式仍待原型验证。

## 小场景如何避免变成静态对话框

- **让信息藏在具体物件里。** 玩家可以检查药包、待验证的异样痕迹或药柜，而不只是轮流点对白选项；具体线索含义不预先定案。
- **让操作前后有可见变化。** 药材被取走、药炉状态变化、账目改变、来客姿态与语气变化，都让选择落在空间里。
- **让物件状态帮助理解，不先定义病因。** 矿砂、药包等最多作为待验证线索，不把猜测画成确诊结果。
- **让分支集中在本轮核心选择。** 只保留两种都有效的治疗方案；修习／考核与周转只是账面机会成本，不扩成剧情线。
- **保留可继续的基础救治。** 漏看线索或控火失手均不能卡关；本轮不额外加入药签、转诊或其他治疗路线。

## 首版建议验证的问题

- 玩家能否在同一间药铺里感觉到“我在调查、判断和操作”，而非只是在一个菜单里读对白？
- 哪些店内物件真的能帮助玩家理解人物处境或资源代价，哪些只是装饰和负担？
- 让玩家自由决定问诊与调查顺序，是否比强制按固定剧本点击更有代入感？
- 用来客回访、物品状态和简短账目反馈后果，是否足以让玩家记住上次选择？
- 药铺单场景能否验证核心乐趣；什么体验被证明不足时，才需要再投入地图移动或外部场景？

## 本轮记录边界

当前方向是**优先做小型药铺场景，减少 Demo 对大地图和跑图内容的依赖，把时间放在店内互动、决策与核心玩法**。病因、药材（包括稀缺药的具体设定）与控火／炼丹手法仍是待验证假设，不得在灰盒中表现成已经确诊或定案。急治与缓治都有效；漏看线索或控火失手都要保留可完成的基础救治。
