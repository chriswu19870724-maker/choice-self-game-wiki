# 药铺单场景探索与交互草案

> **状态：场景范围方向已表达；具体布局、视角与交互仍是候选。** 本文记录首个 Demo 聚焦药铺内体验的方向，并给出一种可验证的交互组织方式。除“先用小场景深挖核心玩法、暂不投入多地图奔跑与宏大场景”外，以下道具、流程和布局都不是已定案实现。

## 方向

首个 Demo 不必靠玩家走过许多地图来制造探索感。可以把药铺作为主要、尽量唯一的实体场景，让玩家在一间小店里接待来客、观察线索、查验药材、做问诊与炼制，并亲自决定稀缺物资的去向。场景体量小，仍可以通过信息揭露顺序、操作选择和状态变化承载较深的玩法。

用户分享的《深空当铺：可能是偷的》店铺截图可作空间组织灵感：让来客、柜台、库存物品与工作台集中出现在同一个可读空间里。借鉴的是“一间店铺容纳人物、物品与操作”的布局思路，不是照搬作品规则、美术或界面。

外部世界先作为店内决策的背景：矿区发生什么，可由来客的话、衣物上的矿粉、带来的样本或之后的回访呈现；药材采购可先用委托、送货或事件表现。只有当小场景已验证核心体验，再决定要不要增加出店或地图内容。

## 一次来客如何在一间店里展开

以魏槐来求药为例，可以把原本的多个“场景段落”理解为同一药铺里的几个体验阶段，而不是多个地图：

1. **来客抵店：** 从门口、脚步、敲门或来客状态提示开始。玩家不用穿越地图，直接看到来客带来的物品与明显症状。
2. **自由观察与问诊：** 玩家可在柜台、问诊座位和来客随身物之间切换，决定先听他说、检查提神散包装，还是留意袖口矿粉。调查顺序影响信息何时变得清楚，但不能让基本处置被技能门槛锁死。
3. **归纳与沟通：** 把“症状、药物用量、矿区线索”等信息反馈给来客。玩家可以坦白说明不确定性、先处理眼前症状或建议转诊；不需要走到地图另一端才能选路线。
4. **柜台上的资源决定：** 让稀缺药材与常用药以可见库存出现。玩家决定用凝露草救治、留下备考、卖出周转，或改用替代处置；资源变化要能从药柜、账目或物品状态看出来。
5. **工作台上的短操作：** 若选炼丹，转到药铺工作台完成一段短操作。操作影响药效表现或稳定性，但失手应有可理解、可继续的安全结果。
6. **反馈与余波：** 来客当面反馈，带走药物或留下样本；桌面、药柜和账目更新。下一位来客或魏槐回访时，能看出玩家上次选择留下的痕迹。

上述阶段是一种候选流程；不要求每次都完整走一遍，也不预设必须采用点击式或第一人称视角。

## 可验证的空间分区

如果采用固定小店画面，可先考虑四至五个互相关联的交互点：

| 店内位置 | 主要用途 | 可能承载的选择 |
| --- | --- | --- |
| 门口 | 来客进出、等待或回访 | 现在接待、先让对方坐下；日后用人物回访呈现后果 |
| 问诊位 | 对话、观察状态、整理线索 | 先听什么、检查什么、如何表达判断的不确定性 |
| 柜台与药柜 | 查看库存、配药与周转 | 救治、留药、出售或改用常见材料 |
| 工作台 | 炼制与简短操作 | 控火、成型或其他单次清晰操作；具体形式待炼丹原型验证 |
| 师父药签／账目处（候选） | 查询基础提示、观察药铺状态 | 给低技能玩家安全路线；显示必要的轻量资源变化 |

这些位置可以共用一张背景，通过角色姿态、物品状态、可交互提示和简洁镜头反馈表达阶段变化；无需先制作多张大型地图。究竟使用固定镜头、俯视小房间、可点击热点或其他交互方式，仍待原型验证。

## 小场景如何避免变成静态对话框

- **让信息藏在具体物件里。** 玩家可以检查药包、矿砂、袖口或药柜，而不只是轮流点对白选项。
- **让操作前后有可见变化。** 药材被取走、药炉状态变化、账目改变、来客姿态与语气变化，都让选择落在空间里。
- **让同一物件随事件变义。** 例如矿砂起初只是来客带来的东西；玩家解释风险后，它可能成为待查样本；如果玩家没有追问，也可留作之后回访的线索。
- **让分支集中在核心选择，而非铺开内容量。** 每个交互点的价值是揭示信息、改变资源或表达态度，不是让玩家为了完成流程反复点物件。
- **保留可继续的基础路线。** 没有学会技能或漏看线索时，仍可用药签、保守处理或转诊继续故事。

## 首版建议验证的问题

- 玩家能否在同一间药铺里感觉到“我在调查、判断和操作”，而非只是在一个菜单里读对白？
- 哪些店内物件真的能帮助玩家理解人物处境或资源代价，哪些只是装饰和负担？
- 让玩家自由决定问诊与调查顺序，是否比强制按固定剧本点击更有代入感？
- 用来客回访、物品状态和简短账目反馈后果，是否足以让玩家记住上次选择？
- 药铺单场景能否验证核心乐趣；什么体验被证明不足时，才需要再投入地图移动或外部场景？

## 本轮记录边界

当前方向是**优先做小型药铺场景，减少 Demo 对大地图和跑图内容的依赖，把时间放在店内互动、决策与核心玩法**。图片中的空间组织作为参考，不代表已经决定使用完全相同的柜台布局。房间分区、交互方式、视角、镜头、道具清单、来客数量和未来是否扩展地图，仍待讨论与原型验证。
