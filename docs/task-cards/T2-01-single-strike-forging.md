## 目标

从已验收的 Godot 4.7.2 空白工程出发，制作一个可在 Godot Web 运行的最小锻造屏：玩家观察一个清楚可见的时机窗口，主动进行一次“落锤”，并立即看到命中、偏早或偏晚的反馈。

本卡只验证锻造交互的局部，不声称完整 AC-01 或完整核心循环通过，也不构成首个可玩 Demo 的 Chris 验收。

## 规格引用

- `GDD.md`：「每 10 秒的体验承诺」与「机制与操作／铸剑」
- `ACCEPTANCE.md`：AC-01 前两项（主动锻造操作、操作后立即反馈）；本卡仅覆盖局部

## 唯一变更维度

只实现“一次可视化时机过程＋一次落锤输入＋即时结果反馈”。每次尝试只能落锤一次；若需要重试，应由玩家明确触发重置。

## 原型参数与规则

- 时机提示和命中窗口必须在操作前可见；具体时长、窗口位置与宽度暂不锁定，由 Dev 选取便于验证的临时参数。
- 所有临时参数集中在常量或单一数据源中；交付时列出所选值，并明确它们仅为测试假设，不是已批准的平衡数值。
- 规则应确定且可复现：窗口内为“命中”，窗口前为“偏早”，窗口后或计时结束未操作为“偏晚”；不使用隐藏随机判定。
- 每种结果均立即显示短文字或等价的清晰视觉反馈，并允许玩家重新开始一次尝试。
- 不指定剑属性名称或属性数值，不把结果接入后续历练效果。
